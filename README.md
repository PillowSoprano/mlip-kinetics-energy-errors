# Predicting the sign and size of kinetic errors in machine-learned potentials from single-point energies

Code and data for the article of this title (Xiyao Yu, Nanyang Technological University).

Every number and every figure in the paper and its Supporting Information can be reproduced from what is here.
Raw molecular-dynamics trajectories are not deposited: they run to several gigabytes and are regenerated by the
notebooks in `colab/` with the seeds the scripts carry. The quantities derived from them (hop events,
committor increments, per-frame energies and energy errors, diffusion coefficients and rates) are all included.

## Layout

The tree is the one the scripts expect, so every program here runs unmodified from the directory it sits in.

| | |
|---|---|
| `*.py` (top level) | one- and two-dimensional numerical experiments: exact generators, intervals, friction, diffusion, label placement, kinetic loss. Run from the top level; they write into `data/` |
| `ala2/` | alanine dipeptide: teacher and student dynamics, force errors, predictions, acquisition, and the student networks (`student_*.pt`) |
| `li3ocl/` | Li<sub>3</sub>OCl: hop analysis, defect states, reactive dissipation density, intervals; ten universal potentials against the teacher and against DFT (`foundation_*.py`, `mattersim_vs_dft.py`) |
| `lgps/` | Li<sub>10</sub>GeP<sub>2</sub>S<sub>12</sub>: diffusion coefficients (`lgps_diffusion.py`), lithium basins, hops, frame weights and the estimates on the frames of each potential (`lgps_estimates.py`) |
| `colab/` | the production runs as executed (Google Colab notebooks), the batched molecular-dynamics engine and its universal-potential backends (`foundation_md.py`), the MACE teacher and students, equilibrium frames, and in `lgps_results/` the energies of each universal potential on the other potentials' LGPS frames |
| `research_extensions/` | nonlinear response and corrected trial fields (`response_geometry*.py`); force errors weighted by the response flux (`work_weighted/`) |
| `dft/` | density-functional single points: inputs, energies (`E0`, extrapolated to zero smearing), magnetic moments and structures of the hop-path and equilibrium frames of the teacher; `excluded_fused_pairs.txt` lists the hop frames with a fused lithium pair, which were not computed |
| `data/` | analysis outputs, including the predictions computed from reference data (`*_predicted*`, `li3ocl_pred_*`), the energies of the ten universal potentials on the teacher's frames (`li3ocl_universal_*`, `li3ocl_foundation_*`, `li3ocl_mattersim_energies.csv`) and the LGPS results (`lgps_*`) |
| `figs/` | `fig_estimates_data.py`, which assembles the values of Figure 1; `fig1_overview.py`, which computes and draws Figure 3; `structures.py`, which selects and projects the configurations of Figures 4a,b and S8a,b; `dft_panel_data.py`, which computes Figure 4d; and `data/`, the numerical values behind every figure |

## Reproducing

The one- and two-dimensional experiments need only NumPy and SciPy and run in minutes:

```
python doublewell_check.py
python bracket_check.py
cd research_extensions/work_weighted && python flux_checks.py
```

Alanine dipeptide needs OpenMM 8.6 and PyTorch; Li<sub>3</sub>OCl needs MACE and PyTorch; the universal potentials
need mace-torch, chgnet, matgl and, in a separate environment, mattersim. Analyses that read derived data only, such as

```
cd li3ocl && python bracket_vs_rate.py
cd li3ocl && python foundation_second_order.py
cd figs && python fig_estimates_data.py
```

run against `data/` with no simulation at all. The scripts that need raw trajectories or stored hop frames are
`ala2/series_weights_check.py`, `ala2/model_side_all.py`, `ala2/measure_twoc.py` and, in `li3ocl/`, `analyze_hops.py`, `defect_states.py`, `clean_channel.py`,
`dV_profile.py`, `student_side.py`, `student_paths.py`, `select_two_sided.py`, `lattice_integrity.py` and `students_table.py`;
regenerate the trajectories with the notebooks in `colab/` first. The LGPS scripts read the trajectories that
`colab/lgps_md.ipynb` writes into `colab/lgps_results/`, next to the cross energies stored there; `li3ocl/foundation_vs_teacher.py`
(modes `prepare_all`, `base_all`, `mattersim_all`, `mace_all`) recomputes the energies on the teacher's frames. `li3ocl/mp0_vs_dft.py` needs mace-torch, which fetches MACE-MP-0 (small) on first use; `figs/structures.py` redraws Figures 4a,b and S8a,b from the stored frames in `figs/data/`.
